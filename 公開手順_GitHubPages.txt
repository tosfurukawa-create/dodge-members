 出場メンバー管理アプリ を インターネットに公開する手順
 （GitHub Pages / 無料・パソコン操作は最小限）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このとおりに上から順番に進めれば公開できます。
むずかしいコマンド操作はありません。ブラウザ（Chrome や Safari）だけで進めます。
公開すると、スマホでURLを開いて「ホーム画面に追加」でき、アプリとして起動・
オフラインでも動くようになります。

※所要時間の目安：15〜20分（アカウント作成を含む）


────────────────────────────────────────
 ● 準備できていること（こちらで完了済み）
────────────────────────────────────────
・PWA一式（manifest / sw.js / アイコン）… 動作確認ずみ
・.nojekyll … GitHub Pages で日本語ファイル名をそのまま配信するための設定
・全ファイルのパスが「相対指定」なので、どんなURLでも正しく動きます
→ あなたがやることは「GitHubに登録 → ファイルを上げる → 公開をON」の3つだけ。


────────────────────────────────────────
 A. GitHub アカウントを作る（持っている人は B へ）
────────────────────────────────────────
1. ブラウザで  https://github.com/signup  を開く
2. メールアドレス・パスワード・ユーザー名を入力
   ※ユーザー名は公開URLの一部になります。
     例）ユーザー名を「miwa-dodge」にすると、公開URLは
        https://miwa-dodge.github.io/…  になります。
     チーム名など、わかりやすい半角英数字がおすすめ。
3. 届いたメールで認証を済ませる（無料プランでOK）


────────────────────────────────────────
 B. 置き場所（リポジトリ）を作る
────────────────────────────────────────
1. ログインした状態で  https://github.com/new  を開く
2. 「Repository name（リポジトリ名）」に半角英数字で入力
   例）dodge-members   ← これも公開URLの一部になります（日本語は不可）
3. 「Public（公開）」を選ぶ
   ※無料プランで GitHub Pages を使うには Public が必要です。
     中身は本アプリのファイルだけなので公開して問題ありません。
4. 緑の「Create repository」ボタンを押す


────────────────────────────────────────
 C. アプリのファイルをアップロードする
────────────────────────────────────────
1. 作成直後の画面にある
   「uploading an existing file」というリンクを押す
   （見当たらなければ 「Add file」→「Upload files」）
2. パソコンでこのフォルダ
   （ドッジボール出場メンバー管理アプリ）を開く
3. 次のファイルを選んで、ブラウザの点線ワク内へドラッグ＆ドロップ：

      ☑ index.html
      ☑ 出場メンバー管理_v1.html
      ☑ manifest.webmanifest
      ☑ sw.js
      ☑ icon-192.png
      ☑ icon-512.png
      ☑ apple-touch-icon.png
      ☑ .nojekyll            ← 忘れやすいので注意
      （任意）はじめにお読みください.txt

   ※ CLAUDE.md は開発用のメモなので、上げなくてOKです。
   ※ .nojekyll が Finder で見えないとき→
      Mac：フォルダを開いて「Command + Shift + .（ピリオド）」で隠しファイル表示。
      それでも面倒なら、GitHubの画面で「Add file → Create new file」を押し、
      ファイル名の欄に  .nojekyll  と入力して中身は空のままCommitしてもOK。
4. 画面下の緑の「Commit changes」ボタンを押す（アップロード確定）


────────────────────────────────────────
 D. 公開（GitHub Pages）をONにする
────────────────────────────────────────
1. リポジトリ上部の「Settings（設定）」を押す
2. 左メニューの「Pages」を押す
3. 「Build and deployment」の
   ・Source ：「Deploy from a branch」を選ぶ
   ・Branch ：「main」／フォルダは「/ (root)」を選び「Save」
4. 1〜2分待って画面を再読み込みすると、上のほうに公開URLが出ます：

      https://（ユーザー名）.github.io/（リポジトリ名）/
      例）https://miwa-dodge.github.io/dodge-members/

   このURLがアプリのアドレスです。ブックマーク推奨。


────────────────────────────────────────
 E. スマホでホーム画面アプリにする
────────────────────────────────────────
・iPhone（Safari）：URLを開く →「共有」ボタン →「ホーム画面に追加」
・Android（Chrome）：URLを開く → メニュー(⋮) →「アプリをインストール」
                     または「ホーム画面に追加」
→ アイコンから起動でき、電波が無い会場でも使えます（オフライン対応）。


────────────────────────────────────────
 F. 【重要】今までのデータを引き継ぐ
────────────────────────────────────────
ブラウザで使っていたデータと、ホーム画面アプリのデータは
別々に保存されることがあります。移すときは：
 1. これまで使っていた画面で、アプリの「名簿」タブ最下部
    →「バックアップ書き出し」でJSONファイルを保存
 2. 新しいホーム画面アプリを開き、同じ場所の「読み込み」で取り込む


────────────────────────────────────────
 ● アプリを直したとき（更新のしかた）
────────────────────────────────────────
1. 直したファイル（例：出場メンバー管理_v1.html）を、Cの手順で
   同じ名前のままアップロード → Commit。自動で上書きされます。
2. スマホ側にすぐ最新を届けたいときは、sw.js の中の
      var CACHE = 'dodge-member-cache-v1';
   の末尾の番号を v2, v3… と1つ上げてから、sw.js もアップロードします。
   （今回の初回公開では、この作業は不要です）


────────────────────────────────────────
 ● なぜこのフォルダに「git」を作らなかったか
────────────────────────────────────────
このフォルダは Google Drive 同期です。git 管理用の隠しフォルダ（.git）は
非常に多くの小さいファイルの集まりで、Drive が同期すると「競合コピー」や
データ破損を起こしやすいためです（CLAUDE.md でも Win/Mac の同時編集を警告）。
そのため、上のブラウザからのアップロード方式が安全でおすすめです。


────────────────────────────────────────
 ● 付録：パソコンに詳しい人向け（gitで更新したい場合・任意）
────────────────────────────────────────
Google Drive の「外」に作業用コピーを作ってから git を使ってください。
（Drive 内で git init するのは避ける）

  例）
    # Drive の外にコピー
    cp -R "（このフォルダ）" ~/dodge-members-git
    cd ~/dodge-members-git
    git init
    git add index.html 出場メンバー管理_v1.html manifest.webmanifest \
            sw.js icon-192.png icon-512.png apple-touch-icon.png .nojekyll
    git commit -m "公開用ファイル"
    git branch -M main
    git remote add origin https://github.com/（ユーザー名）/（リポジトリ名）.git
    git push -u origin main
  以後は編集 → git add → git commit → git push で更新。
  公開ONの操作（Dの手順）は初回に一度だけ必要です。
